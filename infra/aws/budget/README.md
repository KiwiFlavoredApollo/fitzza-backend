# FITZZA-221 예산 설정 요청안

2026-10-17 로컬 준비. **AWS 예산 생성·비용 조회·메일 전송은 실행하지 않았다.**
현재 사용자의 payer 권한 제약은 Jira FITZZA-221에 기록되어 있다.
아래는 관리자가 검토할 요청안이며 실제 설정 완료 기록이 아니다.

## 관리자 설정 요청

| 항목 | 요청값 |
| --- | --- |
| 대상 | FITZZA linked account `414901227428` |
| 전체 프로젝트 상한 | USD 124 (원화 승인 상한 170,000원; 환율에 따른 동일성 보장 아님) |
| 종류·기간 | COST, CUSTOM, 2026-10-15 ~ 2026-11-05 UTC 일자 기준 |
| 시작·종료 | 10/15 00:00Z ~ 11/06 00:00Z, 종료 경계 전까지 |
| 실제 비용 알림 | 50% 초과 USD 62 / 80% 초과 USD 99.20 / 100% 초과 USD 124 |
| 비용 기준 | Unblended, 세금 포함, 크레딧·환불 제외 |
| 수신자 | 사용자가 승인한 이메일을 별도로 확인해 입력 |
| 자동 조치 | 없음. Budget Actions·자동 종료·유료 보고서 추가하지 않음 |

`budget.example.json`, `notifications.example.json`은 검토용이다.
수신자 placeholder를 대체하기 전에는 적용하지 않는다. payer 관리자 권한을 가진
주체가 실행하며 `--account-id`에는 **예산 소유 payer 계정 ID**를 사용한다.
LinkedAccount 값은 비용 필터이며 payer 계정 ID가 아니다.
같은 범위의 기존 예산이 있으면 중복 생성하지 말고 기존 설정을 점검한다.

총액은 10~11월 합산 USD 124다. **월별 USD 124 예산 두 개로 대체하지 않는다.**
CUSTOM 기간은 [AWS Budget API](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_budgets_Budget.html)에 근거한다.
실제 집행 기준이 한국 시간 경계 또는 세금 제외라면 관리자와 합의 후 기간·기준을 맞춘다.

현재 코드에 Project=fitzza와 ALB의 Project=Fitzza가 혼재하므로 태그 누락 위험을
피하기 위해 linked account 전체를 포함한다. 다른 프로젝트와 계정을 공유한다면
과대 집계될 수 있어 전용 계정 여부를 확인한다. 확인 전 임의로 비용을 제외하지 않는다.

## 완료 증적 (10/20 목표)

- BudgetName·기간·금액·linked account 필터의 관리자 설정 증적.
- 50/80/100% 알림과 승인된 수신자 등록·전달 경로 확인.
- 알림은 지출 차단 장치가 아니며 비용 반영 지연이 있어 수동 추적을 계속한다.
- 관리자 응답/권한이 없으면 "설정 대기"로 남기고 완료 처리하지 않는다.
- 예산 종료 후에도 자원 과금은 계속될 수 있어 자원 정리 증적을 별도로 확인한다.
