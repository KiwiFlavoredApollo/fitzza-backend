# Cloud crawler source

Source copied from the project's `fashion-crawler-starter` on 2026-10-21.
Only Python source, tests and pinned direct requirements are included; no data,
environment files, credentials or bytecode are copied.

Build from this directory for the existing ARM64 EKS node:

```powershell
docker buildx build --platform linux/arm64 --load -t fitzza-crawler:pilot .
```

The image entrypoint is `python -m src.cli`; its working directory is `/work`.
Mount a writable execution volume there. The non-root UID/GID is 10001.
Set `SEED_MANIFEST` to the mounted manifest generated by `../build_seed_manifest.py`.
Discovery excludes its product IDs from both cached and newly fetched candidates.
The seed file must remain available when resuming discovery.

`src.cloud_pilot` supports a bounded cloud pilot: one category, at most two pages
per sort, and at most five newly screened products. It reads the seed manifest from
S3 and writes discovery/screening checkpoints plus a report back to the run prefix.
It never runs Jev or embeddings and never marks the data approved for indexing.

This is not yet a complete production Job: recurring checkpoints during large
screening runs, restart recovery and selection of category/season deficits
must be connected before full collection. Discovery still oversamples the original
3000-product targets; candidate counts are not accepted-product counts. Never
interpret a successful CLI exit as proof of quota or color-image quality completion.

The fixed pilot manifest in `../crawler-pilot-job.yaml` starts suspended. Its
dedicated Pod Identity can read only the seed manifest and write only the pilot
output prefix. `../run_pilot_maintenance.py --state <new-state-file>` records original
AI service replicas and the CD Deploy transition, pauses only recommendation/vton,
and restores them after the bounded Job. Do not run it until the immutable image
tag exists in ECR. After an interrupted operator session use the same script with
`--recover --state <saved-state-file>`; recovery must be checked before enabling CD.
The local operator's AWS profile is `fitzza`; no static credentials enter the Pod.

Test without network collection:

```powershell
python -B -m unittest discover -s tests -v
```
